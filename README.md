# README

## Qué es
Es una pequeña página personal para presentar mi perfil, habilidades y una acción interactiva con React y Tailwind.

## Cómo correrlo
```bash
npm install
npm run dev
```

## Uso de IA
- Usé chat de IA para revisar la estructura y darle el estilo general una vez la app era funcional.
- Para esto usé Copilot desde VsCode

## Lo que me costó
Lo más difícil fue ajustarme al uso de @theme para el uso de estilos.
